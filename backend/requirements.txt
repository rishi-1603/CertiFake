# Every version below is pinned exactly (Day-7 remediation, finding S13).
# `numpy`, `opencv-python-headless` and `psycopg2-binary` previously used `>=`,
# so two builds of the same commit could install different code -- a
# reproducibility and supply-chain problem, and it made the dependency audit a
# moving target. Each pin matches a version this test suite was run against.
#
# The resulting set is clean under `pip-audit`: "No known vulnerabilities
# found", with zero waivers. The CI security-scan step gates on that (it used
# to run `pip-audit --desc || true` with continue-on-error, so a green build
# once reported 77 known vulnerabilities across 10 packages).
# ---------------------------------------------------------------------------
